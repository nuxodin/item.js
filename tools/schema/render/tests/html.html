render/html.js

Same API as render/dom.js, but produces an HTML string (for SSR, templating, tests). The right column below shows the same string inserted into the live DOM via innerHTML, so you can see the :valid / :invalid state.

toInput() — schema → HTML string

Escaping

Values from the schema are escaped in both attribute and text positions.

Void tags

Tags listed in VOID_TAGS are serialized without a closing tag.

indeterminate → data-indeterminate

HTML has no indeterminate attribute, so it maps to data-indeterminate.
